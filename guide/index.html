Device connection guide

Thêm thiết bị vào Xiaozhi Console

Add your device to Xiaozhi Console

Làm theo 3 bước bên dưới để đăng nhập, bấm Add Device, sau đó nhập mã kích hoạt hiện trên màn hình thiết bị.

Follow the 3 steps below to sign in, select Add Device, then enter the activation code shown on your device screen.

Tải ứng dụng Download app Android
1

Đăng nhập vào Xiaozhi

Sign in to Xiaozhi

Mở https://xiaozhi.me/, nhập thông tin đăng nhập của bạn, rồi vào Xiaozhi Console.

Open https://xiaozhi.me/, enter your login details, then go to Xiaozhi Console.

2

Chọn Add Device

Select Add Device

Trong trang Agents, bấm nút Add Device được khoanh đỏ ở bên phải màn hình.

On the Agents page, click the Add Device button highlighted in red on the right side of the screen.

3

Nhập mã kích hoạt

Enter the activation code

Lấy mã trên ảnh đầu tiên của thiết bị, nhập vào hộp mã trên website, sau đó hoàn tất kết nối.

Use the code from the first device image, enter it into the code field on the website, then finish pairing.
